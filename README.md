# THE HARMONIC SERIES · additive synth

> A sphere of **UD0** — the ROOT0 universe / biosphere. Domain: **THIS ONE TIME AT BAND CAMP**.

THE HARMONIC SERIES — a playable BAND CAMP instrument kept by THE GRIOT: pluck one string and you hear a ladder of overtones (2f, 3f, 4f…) whose amplitudes ARE the instrument's voice. Drag the bars to shape the spectrum, tap PLAY and the page sums that many sine oscillators live via the Web Audio API — no samples. Presets are the exact classical spectra (sawtooth = all harmonics 1/n, square/clarinet = odd only, pure = fundamental). Fourier made audible: timbre is the overtones. &#9670; LIT the additive synthesis (n·f partials, generated live); AMBER real tones also have inharmonic/noisy/time-varying partials.
